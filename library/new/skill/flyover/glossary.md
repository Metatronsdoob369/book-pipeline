# Glossary — flyover

**Anchors** — hover-read fiducials (origin + roof/lot corners) in `anchors.json`; permanent per site; the invariant datum (Ch 6, 7)
**anchor_pixels.csv** — per-frame pixel position of every anchor; the acceptance test for generated video (Ch 6, 7)
**Aspect gate** — mesh depth/width ratio check; demoted to reporting-only after the Solar API cross-check (Ch 9)
**Best-of-N** — generate N clips, score, pick only if the winner clears a margin; oracle@N vs pass@1 separates "more samples" from "better generator" (Ch 2)
**Checked truth** — doctrine leg: nothing reaches the Commander unverified (Ch 1)
**Commander** — Joe / Preston; vision, taste, money/creds/outward calls (Ch 1)
**Control signal / guide passes** — per-frame depth, object ID, normals rendered from measured geometry along the camera path (`guide_passes_blender.py`) (Ch 2, 3)
**do_not_call** — tag for measured rows that are not sales leads (decks, university, government, right-of-way, duplicates) (Ch 4)
**DRIFTED / HELD / HALLUCINATED** — truth-gate verdicts (Ch 2, 3)
**ECEF-local** — Earth Studio "Local" export space: Earth-centred axes shifted to the origin; not ENU (Ch 6)
**ENU** — east/north/up frame at the site origin; every camera and mesh is brought into it (Ch 2, 6)
**EPT** — USGS 3DEP Entwine Point Tile lidar hierarchy; walk once per box, cache nodes (Ch 4)
**Flight** — `move.json`; disposable per move (Ch 6, 7)
**Fracture** — a recorded failure mode, stated as "never hire again" (Ch 5)
**Generated skin** — doctrine leg: the look may be generated (Ch 1, 2)
**GPU Guardian** — local GPU referee; `gpu run --vram N --exclusive`; GUARD state blocks leases (Ch 1, 4, 10)
**HABS** — Historic American Buildings Survey measured drawings; a measurement source for heroes (Ch 2, 11)
**Hero** — the subject building; gets one fixed skin and must stay accurate (Ch 3)
**Hero frame share** — fraction of frame pixels covered by the hero; ≥5 % per frame for a trustworthy gate (Ch 4)
**Hero skin composite** — fixed texture pass laid over AI frames; source of thin detail (Ch 3)
**Measured skeleton** — doctrine leg: never invent geometry or numbers (Ch 1, 2)
**Measurement rig** — G-buffer/wire/mask renders used for verification; distinct from the beauty render (Ch 9)
**Pixel floor** — IoU degradation from fixed edge error when the hero is small (Ch 4)
**proximity_only** — a photo near the building with no other tie; not counted as showing it (Ch 4)
**Provenance tags** — `[verified <date>]` vs `[relayed]` on every claim (Ch 8)
**quotable=false** — flag on hand-massed geometry/specs that must not yield quotes (Ch 7)
**Result card / Task card** — specialist ↔ manager message formats (Ch 1)
**Route A** — measured depth video + real photo → Wan2.2 Fun-Control → photoreal geometry-locked clip (Ch 2, 3)
**Route B** — real-photo Gaussian splat along the path (to verify) (Ch 2)
**Route C** — Marble world for surroundings only (Ch 2)
**Route D** — free-form image-to-video, gated; for thin-data sites (Ch 2)
**Site** — `anchors.json` + data folder; permanent (Ch 6, 7)
**Structure-locked diffusion** — diffusion confined to an enhancement pass conditioned on deterministically rendered geometry (Ch 8)
**Top offset** — `top_offset_m` (default 3): top keys moved off the camera target to avoid a 180° flip (Ch 6)
**Truth gate** — silhouette render → SAM 2 seeded track → per-frame IoU / boundary-F / depth check (Ch 2)
**Two-tier gate** — Tier 1 deterministic content checks; Tier 2 advisory vision QA that skips, never fakes PASS (Ch 5, 9)
**v1 / v2** — v1: location-agnostic cinematic flyover; v2: roof/shingle visualization built on v1 (Ch 7, 8)
**World bake** — projecting generated frames onto geometry so new cameras render without new generation (Ch 3)
